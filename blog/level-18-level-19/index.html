Level Goal

The password for the next level is stored in a file readme in the home directory. Someone has modified .bashrc to log us out immediately whenever we log in over SSH.

Solution

Log in using ssh -p 2220 bandit18@bandit.labs.overthewire.org and the password obtained in the last level. On a normal login attempt, the session drops back to our own terminal before we can type anything — .bashrc runs on every interactive login and this one ends the session straight away. We never actually need an interactive shell here, though: SSH lets us pass a command directly on the command line, which it runs over the connection instead of starting the usual interactive shell (and instead of the environment that triggers .bashrc's startup logic in the same way). We pass cat readme as that command, so the file's contents come back to our terminal before the connection closes.

This works because a non-interactive SSH command and a login shell trigger different startup behavior. SSH.com's guide to running remote commands over SSH covers that distinction directly. linuxize's explanation of .bashrc vs. .bash_profile is useful background on why .bashrc is the file that got weaponized here in the first place.
