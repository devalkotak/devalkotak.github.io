Level 19 → Level 20

11 Aug 2026Linux

Level Goal

To gain access to the next level we should use the setuid binary bandit20-do in the home directory. Running it without arguments shows how to use it; the password for this level is in the usual place (/etc/bandit_pass) once we've used the binary correctly.

Solution

Log in using ssh -p 2220 bandit19@bandit.labs.overthewire.org and the password obtained in the last level. We can't read /etc/bandit_pass/bandit20 directly, since that file belongs to bandit20 and we're logged in as bandit19. bandit20-do has its setuid bit set and is owned by bandit20, though, so when we execute it, it runs with bandit20's permissions instead of ours, regardless of who invoked it. Running it bare shows it expects a command as an argument and executes that command as bandit20, so we hand it cat /etc/bandit_pass/bandit20 and it reads the file on our behalf.
