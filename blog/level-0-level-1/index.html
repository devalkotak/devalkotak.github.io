Level Goal

The password for the next level is stored in a file called readme located in the home directory. Use this password to log in to user bandit1 on the same host and port.

Solution

Log in using ssh -p 2220 bandit0@bandit.labs.overthewire.org and the password from Level 0. When we SSH in we are placed in the home directory, which we confirm with pwd. We then use ls to list the directory, where we find a readme file, and use cat to print its contents and read the password for the next level.
