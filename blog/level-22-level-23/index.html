Level Goal

A program is running automatically at regular intervals from cron. We look in /etc/cron.d/ for the configuration to see what command is being executed.

Solution

Log in using ssh -p 2220 bandit22@bandit.labs.overthewire.org and the password obtained in the last level. Same pattern as the last level: /etc/cron.d/cronjob_bandit23 points at a script, and we cat it to see what it does. This time the output filename isn't fixed in the script — it's computed at runtime as the MD5 hash of the string "I am user bandit23" (the script builds that string from whoami, so it's really hashing whichever user runs it). Since we know the exact string the script hashes, we don't need to wait and go looking for the file — we can just compute the same MD5 hash ourselves with md5sum and read that filename directly under /tmp.
