Level Goal

The password for the next level is stored in the file data.txt and is the only line of text that occurs only once.

Solution

Log in using ssh -p 2220 bandit8@bandit.labs.overthewire.org and the password obtained in the last level. We find data.txt in the home directory and confirm it's too long to read by eye - 1001 lines, with duplicates throughout and just one unique line holding the password. We pipe data.txt through sort (so identical lines sit next to each other) and then through uniq -u, which prints only lines that appear exactly once, leaving just the password.
