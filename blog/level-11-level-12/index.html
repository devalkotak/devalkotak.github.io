Level 11 → Level 12

2026-08-11Bandit

Level Goal

The password for the next level is stored in the file data.txt, where all lowercase (a-z) and uppercase (A-Z) letters have been rotated by 13 positions (ROT13).

Solution

Log in using ssh -p 2220 bandit11@bandit.labs.overthewire.org and the password obtained in the last level. cat-ing data.txt shows readable text, but it's scrambled — every letter has been shifted 13 places through the alphabet, wrapping from z back to a. Since ROT13 is its own inverse (applying it twice returns the original text), we run the same rotation again to undo it. We use tr to remap each letter: the first range A-Za-z is the set of characters to translate, the second range N-ZA-Mn-za-m is what each of those characters becomes, shifted 13 positions.
