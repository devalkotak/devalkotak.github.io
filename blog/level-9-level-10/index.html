2026-08-11Bandit

Level Goal

The password for the next level is stored in the file data.txt in one of the few human-readable strings, preceded by several = characters.

Solution

Log in using ssh -p 2220 bandit9@bandit.labs.overthewire.org and the password obtained in the last level. data.txt here is mostly binary data, so a plain cat is unreadable. We use strings to pull out only the human-readable sequences in the file, then pipe that through grep for ==, since the password line is preceded by several = characters and that pattern is rare enough to isolate it from the other readable strings in the file.
