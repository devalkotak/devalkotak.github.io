Level 16 → Level 17

2026-08-11Bandit

Level Goal

The credentials for the next level can be retrieved by submitting the password of the current level to a port on localhost in the range 31000-32000. Only one of the listening ports actually hands back credentials — the rest just echo whatever we send.

Solution

Log in using ssh -p 2220 bandit16@bandit.labs.overthewire.org and the password obtained in the last level. A thousand-port range is too wide to probe by hand, so we scan it first with nmap -sV to see which ports are open and which service nmap thinks is running on each. Most of the open ports either echo our input back or drop the connection; the one that matters is the port nmap can't fingerprint a normal service on but that responds to an SSL handshake. We confirm that with openssl s_client the same way as the previous level, then submit the password. Since this level hands us an SSH key instead of a plaintext password (same pattern as level 13), the response is a private key we redirect into a file, lock down with chmod 600, and use to log into bandit17.
