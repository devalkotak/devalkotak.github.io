Level 13 → Level 14

11 Aug 2026Linux

Level Goal

The password for the next level is stored in /etc/bandit_pass/bandit14 and can only be read by user bandit14. For this level we don't get the next password directly — we get a private SSH key (sshkey.private) that logs us in as bandit14 instead.

Solution

Log in using ssh -p 2220 bandit13@bandit.labs.overthewire.org and the password obtained in the last level. sshkey.private sits in the home directory, so we use it directly with ssh -i to authenticate as bandit14 without a password. SSH refuses to use a private key file that's readable by group or others (it warns UNPROTECTED PRIVATE KEY FILE! and aborts), so we chmod 600 it first to restrict it to our own user. Once logged in as bandit14, the level's own password file is finally readable, since we're now that user.
