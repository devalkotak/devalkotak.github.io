Level 20 → Level 21

11 Aug 2026Linux

Level Goal

There's a setuid binary suconnect in the home directory. It connects to localhost on whatever port we pass it as an argument, reads a line of text from that connection, and compares it to the password of the next level (bandit21), which it already knows internally. If what we send matches, it sends back the password for bandit21.

Solution

Log in using ssh -p 2220 bandit20@bandit.labs.overthewire.org and the password obtained in the last level. suconnect is the client here, not the server, so it needs something listening on the port we give it before it has anything to connect to. We open a second terminal session (a second SSH connection to bandit20) and start nc -l listening on an arbitrary local port, feeding it the current level's password as the data it'll send once something connects. Back in the first terminal, we run ./suconnect <port> against that same port. suconnect connects to our listener, reads the password we fed it, and since it matches what suconnect expected, it prints the password for bandit21 straight to our first terminal.
